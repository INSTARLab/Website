Public record

A timeline you can check.

Every entry below comes from a public record that was opened and read: the IRS determination letter, the Ohio Attorney General and ProPublica listings, and the public GitHub history of this website. Each one links to where you can verify it yourself.

What is not here is deliberate. Where no public record states a date, such as a first program or first event, we leave it out rather than guess. See the full public record.

Institutional timeline

16 dated entries, oldest first.

Show

  1. 8 December 2019Open code

    Public website repository created on GitHub

    The INSTARLab/Website repository was created with an initial commit holding a licence and a README. GitHub records the creation timestamp as 2019-12-08.

    Source: GitHub commit c4ac512 (Initial commit), retrieved 23 October 2026

  2. 9 December 2019Open code

    First website files committed

    The next day a first commit added 188 files, among them the home, about and 404 pages: the earliest version of the site that survives in public history.

    Source: GitHub commit 30eb3a7 (Initial), retrieved 23 October 2026

  3. 27 April 2020Legal status

    IRS 501(c)(3) exemption takes effect

    The IRS determination letter for INSTAR Lab Inc (EIN 85-0845517), dated 14 May 2020, gives 27 April 2020 as the effective date of exemption and classifies the organization as a public charity under section 170(b)(1)(A)(vi).

    Source: IRS determination letter (PDF), retrieved 23 October 2026

  4. 27 April 2020Public filings

    Ohio Attorney General record lists the date founded

    The Ohio Attorney General charitable registration record for INSTAR LAB INC shows "Date Founded" as 4/27/2020, organization type 501(c)(3), registration status Registered. The date is the one the state record publishes.

    Source: Ohio charity registration, retrieved 23 October 2026

  5. May 2020Public filings

    ProPublica lists the tax exemption as issued

    ProPublica Nonprofit Explorer, keyed to the EIN, shows "Tax exemption issued: May 2020", matching the month of the IRS letter.

    Source: ProPublica Nonprofit Explorer, retrieved 23 October 2026

  6. 2020Public filings

    First annual filing listed: fiscal year 2020

    ProPublica lists a Form 990-N (e-Postcard) filing for each fiscal year ending December from 2020 through 2025. A postcard carries no financial details; it is the filing used by organizations with gross receipts under $50,000.

    Source: ProPublica Nonprofit Explorer, retrieved 23 October 2026

  7. 20 June 2023Open code

    Second public repository: startheory

    INSTARLab/startheory was created on GitHub, a second public repository in the organization. It has no published description; this entry records only that it exists and when it was created.

    Source: GitHub repository INSTARLab/startheory, retrieved 23 October 2026

  8. 2025Public filings

    Most recent annual filings: fiscal year 2025

    ProPublica shows a Form 990-N postcard for the fiscal year ending December 2025, the latest year listed when the record was read.

    Source: ProPublica Nonprofit Explorer, retrieved 23 October 2026

  9. 2025Public filings

    Ohio annual report on file for filing year 2025

    The Ohio Attorney General record shows 2025 as the most recent report filing year and answers "Yes" to compliance with registration and filing requirements. The figures in that report are self-reported; see the Record for how they are framed.

    Source: Ohio charity registration, retrieved 23 October 2026

  10. 1 March 2026Website

    Site redesign: Bootstrap 5 and accessibility pass

    A commit upgraded the site from Bootstrap 3.3.6 to 5.3.3 and added accessibility structure (main landmarks, aria labels, alt text, heading hierarchy) and a shared set of interior page templates.

    Source: GitHub commit 67a16b0, retrieved 23 October 2026

  11. 15 June 2026Website

    Dedicated Leadership page added

    A commit replaced placeholder cards on the home page with real leadership entries and added a dedicated Leadership page.

    Source: GitHub commit 4810579, retrieved 23 October 2026

  12. 25 June 2026Website

    Accessible navigation overhaul merged

    Pull request #217 merged a site-wide, accessibility-focused rebuild of the navigation, touching 67 files.

    Source: GitHub merge 60dafd0 (pull request #217), retrieved 23 October 2026

  13. 19 July 2026Open code

    Automated HTML, link and accessibility checks added to CI

    A merge added continuous-integration checks for HTML validity, broken internal links and accessibility, plus a scheduled site-health sweep.

    Source: GitHub merge 72efb62, retrieved 23 October 2026

  14. 19 August 2026Open code

    Migration to the Astro 7 static-site framework begins

    The first commit of the Astro v7 foundation added the build configuration and package setup that the current site is built with.

    Source: GitHub commit b695800, retrieved 23 October 2026

  15. 29 August 2026Website

    Research route published through the hardened Pages mirror

    A release merge published the research overview route and tightened the pipeline that mirrors the built site to GitHub Pages.

    Source: GitHub merge fe5b0cd, retrieved 23 October 2026

  16. 2 September 2026Website

    Astro site promoted to the live branch

    The demo (staging) branch was merged into gh-pages, the branch GitHub Pages serves, carrying 27 changed files including the Astro configuration.

    Source: GitHub merge 647d560, retrieved 23 October 2026
